## 🐛 Troubleshooting

### Issue 1: No Network Request Appears

**Possible Causes**:
1. ❌ Form validation failed silently
   - **Check**: Look for "Validation FAILED" in console logs
   - **Fix**: Make sure all 3 liveness photos are captured

2. ❌ Button is disabled
   - **Check**: Click the button - does cursor show loading?
   - **Fix**: Wait for camera step to complete

3. ❌ JavaScript error before API call
   - **Check**: Look for red errors in console
   - **Fix**: Report the error with full stack trace

### Issue 2: Network Request Shows But Gets 400/401/403

**Check these**:

```
400 Bad Request:
  → Payload is malformed
  → Check Response tab for details
  → Usually validation error in backend

401 Unauthorized:
  → Missing or invalid Privy token
  → User not authenticated
  → Check: Are you logged in?

403 Forbidden:
  → User role doesn't have permission
  → Check: Do you have correct user role?

CORS Error (if visible):
  → Origin header mismatch
  → Check: ALLOWED_ORIGINS in API Gateway
  → Should include: https://web-prod-kqr3pbuu3a-uc.a.run.app
```

### Issue 3: Request Times Out (takes >30 seconds)

**Check these**:
1. Network speed - very large files?
2. Backend processing - try smaller files
3. Cloud Run timeout settings

### Issue 4: Success Response But Data Doesn't Appear in Admin

**Check**:
1. ✅ User is authenticated (verify in /api/v1/users/me)
2. ✅ Go to admin dashboard: `https://web-prod-kqr3pbuu3a-uc.a.run.app/admin/kyc`
3. ✅ Refresh the page if needed
4. ✅ Check browser console for admin fetch errors
